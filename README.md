# benchmark-samples

Sample tasks for evaluating AI models on code-driven 3D and game work. Each
task has an input the model sees, a hidden answer key, and verifiers that grade
the model's output.

| Folder | Domain | Status |
|---|---|---|
| [`blender/`](blender/) | Blender tasks and evaluation scripts | Added |
| `gamedev/` | Godot tasks and tests | Coming soon |
| `cad/` | FreeCAD tasks and graders | Coming soon |
